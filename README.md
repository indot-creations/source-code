🐍 Snake Target Game (Java Swing)

A simple 2D Snake game developed using Java Swing.
The player controls a snake that grows by eating red targets within a limited time.

🎮 Features
🔵 Snake moves automatically
🎯 Eat red targets to grow
🐍 Snake length increases like classic Snake game
⏱ Time limit (30 seconds)
🏆 Win condition (reach target score)
💀 Game Over if time runs out or hits wall
🔄 Restart button
🛠 Technologies Used
Java
Java Swing (GUI)
AWT (Graphics & Events)
📦 Requirements

Before running this project, make sure you have:

Java JDK 8 or higher installed
Any IDE (NetBeans / IntelliJ / Eclipse) OR terminal
🚀 How to Run (Step-by-Step)
1️⃣ Clone the Repository
git clone https://github.com/indot-creations/source-code.git
2️⃣ Open Project
Open the project in your IDE
OR
Navigate to project folder in terminal
3️⃣ Compile the Code
javac simpleJavaGame2.java
4️⃣ Run the Game
java simpleJavaGame2
🎮 Controls
Key	Action
⬅️ Left Arrow	Move Left
➡️ Right Arrow	Move Right
⬆️ Up Arrow	Move Up
⬇️ Down Arrow	Move Down
🧠 Game Rules
Eat red circles to increase score
Each target increases snake length
Reach 10 points to win
If time reaches 0 → 💀 Game Over
If snake hits wall → 💀 Game Over
🔄 Restart Game
After Game Over or Win
👉 Click the Restart Button
